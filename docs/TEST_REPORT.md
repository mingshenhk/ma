- 优化了洗牌：一次读取一批 `crypto/rand` 安全随机字节，并以拒绝采样保持 Fisher-Yates 均匀性，避免每张牌单独请求随机源及创建大整数。自动补桌先单次索引空闲桌，避免每个茶馆玩法重复扫描所有房间；同一玩家的多条 WebSocket 连接复用本次广播的视图 JSON。

- 未改变玩法规则，也未异步化牌局保存。命令处理与本地 JSON 同步持久化仍在单进程串行锁内，慢磁盘时仍可能增加操作延迟。WSL Ubuntu 26.04 / Go 1.26.0 下，本轮改动后执行 `go test ./...`、`go test -race ./...`、`go vet ./...` 均通过；没有现成基准测试，未测量发牌与广播耗时，不宣称卡顿已彻底消除。
