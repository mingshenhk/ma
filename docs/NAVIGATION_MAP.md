# 当前页面与入口

- 首次访问 → 使用用户名和密码注册；已有账号可登录 → 大厅。当前没有密码重置/找回入口。
- 大厅游戏卡/创建房间 → 六款选择、固定人数与配置 → 等待桌。
- 加入房间/邀请链接 → 房号或等待列表 → 入座 → 准备 → 房主开始。
- 牌桌 → 玩家自主响应与出牌、定缺/漂分等玩法阶段（唯一合法响应为过牌时自动过牌）→ 本局结算 → 下一局/总战绩。
- 牌桌解散 → 全体真人投票 → 未完局作废，已完成局保留。
- 底栏战绩 → 参与记录 → 逐局结果与记分账。
- 底栏亲友圈 → 创建/加入 → 成员与角色、设置、圈内开桌、圈内战绩。
- 顶部资料 → 昵称/头像；规则 → 六款完整TXT；反馈 → 文本提交。
- 设置 → 提示音、全屏、添加主屏幕说明、管理入口；无房间时可退出账号。
- 管理入口 → 密钥校验 → 账号/房间/亲友圈/已完成记录/在线统计/反馈。

后端对所有写操作和记录可见性独立校验，隐藏前端按钮不作为权限依据。
