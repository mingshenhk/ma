# 当前功能矩阵

更新：2026-10-24。表中状态指新实现，不代表原版服务器行为已经证实。

| 功能 | 状态与范围 |
| --- | --- |
| 六款玩法 | 原五款2人、新增四川血战暂定版4人；各自规则策略、合法操作及结算，未证明原服全部边界 |
| 大厅/创房/加房 | 原包布局结构参考；六款入口、配置、房号、房间邀请链接、等待牌桌；视觉及交互复刻未完成 |
| 账号/资料 | 用户名/密码注册登录、Cookie会话、昵称和原创头像；暂无密码重置/找回 |
| 牌桌 | 按牌类显示，隐藏他人手牌；准备、玩家自主响应与出牌、规则校验；无电脑补位、托管或操作倒计时 |
| 联机 | HTTP命令、WS快照、心跳重连、版本冲突和请求去重 |
| 解散/结算 | 人类玩家投票、未完局作废、保留已完局和积分账 |
| 战绩 | 参与者/圈内权限查询，结算、记分账、最近事件；无完整逐步录像 |
| 茶馆入馆/成员 | 创建、申请/审核、馆主/管理员/成员、禁玩/移除、暂停加入、公告 |
| 茶馆固定玩法/牌桌 | 新增/修改/启停/删除模板；服务端固定配置开桌，入桌、自动补空桌、管理员解散 |
| 茶馆战绩 | 完成局记录、积分账和成员统计；含部分局数的管理员关闭房间保留已完成局 |
| 茶馆未完成部分 | 消息、馆内邀请、财富操作、大赢家设置、细分权限、完整录像回放；当前需手动刷新馆内列表 |
| 反馈/管理 | 反馈保存、管理密钥鉴权、账号/房间/圈/记录/在线统计 |
| 监控 | 健康检查、鉴权指标、延迟桶、累计CPU与Go内存/协程 |
| 持久化 | 原子JSON快照、重启恢复、失败回滚；单进程单写 |
| 手机/安装 | 响应式布局、图标与manifest、主屏幕说明；无离线缓存 |
| 编译与脚本 | Windows/Linux产物、启动构建打包脚本、Docker/Caddy配置 |
| 公网及生产 | 尚未验收；无多实例数据库、微信登录、短信和真实支付 |

当前是开发验收版，不代表已完成“大部分原版复刻”。逐项差距见 ORIGINAL_PARITY.md，客户确认状态见 RULES_COVERAGE.md，真实验证见 TEST_REPORT.md。
