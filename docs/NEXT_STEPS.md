# 后续工作

当前六款开发验收版可本地启动，但原版复刻范围仍有缺口。后续先补业务与交互，再做生产部署：

1. 客户审阅六款规则 TXT，重点确认四人四川血战基线，以及红二十、斗十四、跑得快标为项目拟定的边界。修改规则应同步更新实现、规则稿及相关回归测试。
2. 按 ORIGINAL_PARITY.md 继续核对并实现茶馆消息/邀请、大赢家设置、细分权限、记录详情等原版流程；财富操作须先明确娱乐积分业务口径。当前固定玩法必选、每玩法补一空桌的行为是项目实现，不伪称原版完全一致。
3. 继续对照原大厅、创房、牌桌、结算的布局和交互；当前只纠正了结构，尚无原客户端实机画面对照验收。
4. 选定部署服务器、域名和备份方式，验证 Docker/Linux 运行、Caddy HTTPS、断网重连以及真实 Android/iPhone 浏览器。上线前以实际对局及目标硬件测量吞吐和长期稳定性。
5. 多进程或多实例部署前替换单写 JSON，实施数据库、并发控制、迁移和备份恢复演练。当前不要多进程共享 DATA_DIR。
6. 微信授权、短信、离线能力、完整逐步录像回放或更丰富电脑策略尚需实现并验收。

发布包使用 start.cmd 启动；源码构建、环境变量和生产限制见 README.md 与 DEPLOYMENT.md。
