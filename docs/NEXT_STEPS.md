# 后续工作

当前六款开发验收版已可本地启动。后续按客户反馈和部署环境推进：

1. 客户审阅六款规则 TXT，重点确认四人四川血战基线，以及红二十、斗十四、跑得快标为项目拟定的边界。修改规则应同步更新实现、规则稿及相关回归测试。
2. 选定部署服务器、域名和备份方式，验证 Docker/Linux 运行、Caddy HTTPS、断网重连以及真实 Android/iPhone 浏览器。
3. 上线前以实际对局及目标硬件测量吞吐和长期稳定性；现有连接扇出数据不等于同时对局人数。
4. 多进程或多实例部署前替换单写 JSON，实施数据库、并发控制、迁移和备份恢复演练。当前不要多进程共享 DATA_DIR。
5. 如需要微信授权、短信、离线能力、完整逐步录像回放或更丰富电脑策略，单独实现并验收。

发布包使用 start.cmd 启动；源码构建、环境变量和生产限制见 README.md 与 DEPLOYMENT.md。
