## 目前仍缺的关键规则

### 红中断勾卡

1. **二人终局**：原文“一家胡后继续，两个玩家胡后结束”，两人局第一人胡后是直接结算，还是继续，另一人怎样继续？这会决定整个血战状态机。
2. **76/72张冲突**：正文72普通牌+4红中=76，海底却写第72张最后一张。需要明确是实际最后一张、留4张，还是旧文案。
3. 二人首庄、换庄/流局连庄；请胡/抓报、多项加番、红中替代后根/456卡/清一色的计算；最好提供一局含杠和抓报的结算例子。

### 无红中断勾卡 ID114

ID、人数已解决。仍缺二人庄闲发牌/终局/换庄和完整付款表；需要明确是否与红中规则只差癞子。ID114客户端会算根和卡，但番提示里累加代码被注释，**根/卡最终是否加番尚不能由客户端裁决**。

### 红二十

1. 52张与6/9/12张大王的关系、完整总牌组；红点怎么算，全黑胡是否豁免20红点。
2. “够20 / 补一张够20”两种听牌的具体区别、暗碰完整流程及是否计碰番、红五/黑五各+5的含义。
3. 报听被抓如何算；滚番/梯番在底分不为1时的公式和封顶顺序。已给底1算例，但不能据此确定全部底分算法。
4. 两人包赔只对应实际另一家，需要确认没有延用多人份数；流局后庄家归属。

### 跑得快

1. **二人精确减牌与留底**：二人客户端每人10张；固定减牌注释候选23张、随机40张。未发出的3/20张怎么处理，是否保证黑桃5在两人手里？截图的三人减10张不能用于二人。
2. 有牌必须压还是能主动过，三连是否开启；四5/四A关牌的时机、优先级、终局和赔付。
3. 炸弹1番的倍率/付款方与封顶方式；剩牌计分与炸弹/关牌如何叠加。现有“剩1张不赔”已明确。

### 斗十四

1. **二人庄闲初始牌数**；“丁斧爷头”对应哪些牌、偷牌是否拿出原牌、连偷及耗尽如何处理。
2. **点数冲突**：截图全红按两头相加，客户端地/幺四/人为4/10/16（牌面和2/5/8的双倍），拉三张又有最低10点。需要确认五门红倍点及拉的点数表。
3. 普通胡门槛、红胡/黑胡定义、天胡地胡、报胡后锁定规则。
4. 滚翻/梯翻、双方漂、500/1000封顶的完整算例，以及二人庄家、流局、点炮/自摸支付规则。
