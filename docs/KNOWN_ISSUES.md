# 已知限制

更新：2026-10-24。此版本用于开发验收和客户体验。

- 规则不是全部已获客户确认。六款完整 TXT 中的项目拟定项是当前执行版本；四人普通麻将采用四川血战暂定版，包内菜单不构成原服规则证明。红二十缺原模块，部分地方玩法仍需客户核对。
- 使用单进程、全局锁和本地 JSON 快照；不支持多实例或多个进程共享数据目录，没有 PostgreSQL/Redis。保存采用临时文件、同步及重命名，但没有目录 fsync、跨文件事务或进程锁。
- 健康检查表示服务已加载，不主动写盘验证可写性。磁盘、权限、备份与恢复仍需运维监控。
- 100/300/500 连接测试为同账号的多 WS 快照扇出，不能推算同时玩家或游戏吞吐；尚未完成公网、长时间真实对局压测。
- Linux 只完成交叉编译；Docker、Caddy TLS、公网域名和实体 Android/iPhone 尚未实际验收。桌面浏览器手机尺寸验证不能替代真机。
- 战绩保留结算、记分账和最近事件，不是整局逐步录像回放。电脑以保守合法动作运行，不能代表真人策略或覆盖每种可选动作。
- 安装图标和主屏幕说明已提供，无离线 Service Worker。没有微信 OAuth、短信、真实支付、充值或提现。
- 登录限流按 RemoteAddr，未信任 X-Forwarded-For；反向代理后的用户可能共用限流桶，需要按部署拓扑进一步设计。
- 会话和恢复码由新系统管理。部署应保护数据目录及管理密钥、启用 HTTPS 和安全 Cookie；发布包不带测试数据。

本实现未使用原私有接口、原代码或原图集音效，因此界面为独立实现，不能宣称原版像素级复刻。
