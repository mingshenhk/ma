# 已知限制

更新：2026-10-25。此版本用于开发验收和客户体验。

- 规则不是全部已获客户确认。六款完整 TXT 中的项目拟定项是当前执行版本；四人普通麻将采用四川血战暂定版，包内菜单不构成原服规则证明。红二十缺原模块，部分地方玩法仍需客户核对。
- 原版复刻未完成。茶馆已补审批、模板、成员权限、牌桌、自动开房和战绩，但仍缺消息/邀请、财富操作、大赢家设置、细分权限及完整录像。当前成员统计的大赢家次数不是原版设置功能；馆内列表依赖手动刷新。
- 茶馆最近7天战绩页与只读外部 API 已实现，但尚未进行微信小程序或真实公网 HTTPS 集成验收。过期战绩立即从查询结果消失，存储清理在启动时及每小时运行；保存失败会留待后续周期重试。接口以房间汇总小局为单位，不提供完整动作回放；`memberId` 根据已保存的房间玩家列表筛选。接口没有独立的请求频率限制，正式开放前需结合部署拓扑设置网关限流和监控。
- 固定玩法是当前茶馆开桌的前提，原包也有未设玩法时自由创房分支；自动开房采用每模板一空桌，原版具体数量未证实。详见 ORIGINAL_PARITY.md。
- 大厅已按原包功能布局组织，美术和响应式实现为自制；尚未完成原客户端实机画面对照，不能称为大部分或像素级复刻。
- 使用单进程、全局锁和本地 JSON 快照；不支持多实例或多个进程共享数据目录，没有 PostgreSQL/Redis。保存采用临时文件、同步及重命名，但没有目录 fsync、跨文件事务或进程锁。
- 健康检查表示服务已加载，不主动写盘验证可写性。磁盘、权限、备份与恢复仍需运维监控。
- 100/300/500 连接测试为同账号的多 WS 快照扇出，不能推算同时玩家或游戏吞吐；尚未完成公网、长时间真实对局压测。
- Linux 只完成交叉编译；Docker、Caddy TLS、公网域名和实体 Android/iPhone 尚未实际验收。桌面浏览器手机尺寸验证不能替代真机。
- 战绩保留结算、记分账和最近事件，不是整局逐步录像回放。当前牌桌仅支持真人玩家，未实现观战和整局逐步录像回放。
- 安装图标和主屏幕说明已提供，无离线 Service Worker。没有微信 OAuth、短信、真实支付、充值或提现。
- 登录限流按 RemoteAddr，未信任 X-Forwarded-For；反向代理后的用户可能共用限流桶，需要按部署拓扑进一步设计。
- 账号使用用户名和密码及安全会话 Cookie；当前没有密码重置/找回、短信或微信登录。部署应保护数据目录及管理密钥、启用 HTTPS 和安全 Cookie；发布包不带测试数据。

本实现未使用原私有接口、原代码或原图集音效，因此界面为独立实现，不能宣称原版像素级复刻。
