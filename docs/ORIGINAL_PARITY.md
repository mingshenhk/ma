# 四川游戏家园对照与当前缺口

更新：2026-10-24。用户目标是复刻大部分四川游戏家园的功能结构和交互。当前工程具备六款开发对局和部分大厅/茶馆业务，尚未达到“大部分复刻完成”的验收结论。之前只列能建房、亲友圈和战绩，低估了原版茶馆范围。

## 六款规则不能混用

| 游戏 | 人数及牌组 | 成牌与结算的主要区别 |
| --- | --- | --- |
| 红中断勾卡150 | 2人；筒条72张+4红中 | 庄11闲10，三坎一对/五对；红中癞子、不能碰杠、限制打出；报胡/请胡/抓报、根/卡、六番封顶；首胡结束 |
| 无红中断勾卡114 | 2人；筒条72张 | 无癞子；其余根/卡按用户要求沿用红中版，首胡结束；不是另一种13张普通麻将 |
| 红二十110 | 2人；52普通扑克+6/9/12王 | 手牌基数8，扑克点数配14；20红起胡及全红全黑特例；王、碰杠、报胡/抓报、自摸奖励，按番表支付 |
| 跑得快115 | 2人；固定23张或随机40张 | 每人10张，比较单张/对子/连牌/飞机/炸弹等出牌；先出完获胜，按余牌、关牌、炸弹结算；没有麻将/吃牌成胡条件 |
| 斗十四95 | 2人；21种骨牌各4共84张 | 手牌基数12，异种骨牌合14，30红起胡及颜色特例；独立红点、碰牌、拉牌/四张奖励、漂分和金额封顶；不套用红二十抓报自摸杠番 |
| 普通无红中麻将（新增） | 4人；万筒条108张 | 庄14闲13、定缺、七对；无红中、不报请、不使用断幺九/456卡番；三人胡或流局结束，四川血战暂定番表 |

无红中与红中版部分相同来自用户明确指示“只是去除红中而已”。共享房间、轮流操作、摸打响应或通用算法属于工程复用；各玩法的牌组、成牌和支付必须由独立策略决定。当前实现有差异回归实例，不能把策略分文件本身当作原服规则已验证。

规则基线为 rules/CLIENT_REVIEW_RULES_SIX_GAMES_2026-10-24.txt。项目拟定项仍待客户审阅，新增四人玩法的原服ID和完整规则未恢复。

## 大厅与茶馆

来源为原包静态解码路径 `plaza/plaza/src/views/layer/plaza/teahouse/`，不执行原程序、不调用原私有服务。`TeaHouse.lua` 注册主页、信息、创建/加入、消息、申请、成员、玩法、邀请、统计、最新战绩、大赢家设置、管理员设置等窗口。`TH_PlayRule` 含自动开房，`TH_Info` 含管理员解散线索，`TH_CalculateDlg` 标注财富操作。源文件在内部 analysis 目录保留，不进入发布包。

| 原版结构/功能 | 当前实现 | 状态及边界 |
| --- | --- | --- |
| 大厅顶栏、左侧加入/创房、右侧游戏列表、底部入口 | 已按结构重新组织 | 部分；没有原实机视觉及动画对照验收，非原图集 |
| 茶馆创建、加入、信息/公告 | 创建、申请加入、加入开关、公告、馆列表 | 已提供开发流程 |
| ApplyList 入馆审核 | 馆主/管理员同意或拒绝，普通成员无权限 | 已提供；重启保存 |
| Member/Manager 成员 | 馆主、管理员、普通成员，禁玩/移除/退出 | 已提供基础权限；缺细分授权设置 |
| PlayRule 玩法 | 新增、编辑、启停、删除模板；服务器固定配置 | 已提供；既有房间不随模板修改 |

| 管理员解散 | 同馆馆主/管理员可关闭房间，保留已完成局和积分 | 已提供；未完成局作废，自动开房开启时会补空桌 |
| UserBattle/ActualTimeInfo/Balance | 完成局记录、积分账、成员局数及净分 | 部分；没有完整录像和原版全部筛选/实时推送 |
| BigWinner 大赢家设置 | 当前只有正分房间次数统计 | 未实现设置；不能将统计次数当成原版功能 |
| Message/InviteChat | 无馆内消息或邀请流程；只有普通房间链接 | 未实现 |
| Calculate/Wealth/Settle 财富操作 | 仅对局娱乐积分账 | 未实现原版操作；不接真实支付/现金 |
| ManagerSet 细分权限 | 当前统一馆主/管理员权限 | 未实现原版逐项授权 |
| 原商城、银行、兑换、福利 | 当前底栏改为战绩、资料、规则、设置、茶馆 | 未实现原商业业务；不得声称入口等价 |

原包存在“未设玩法时自由创房”的分支；当前茶馆要求先启用固定玩法。这是当前实现差异，不是已证明的原版限制。消息、邀请、财富操作、原版大赢家设置、细分权限等后续应继续按证据补齐。原包只有前端线索的地方不能补成“原服已证实”。
