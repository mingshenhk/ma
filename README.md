当前是可本地运行的六款游戏开发验收版，仍在补齐四川游戏家园的大厅、茶馆及交互流程。不能视为“大部分原版功能已复刻完成”。原五款固定两人，新增普通麻将固定四人；使用娱乐积分。当前规则允许先实施、后续修订，尚不能视为客户已确认全部地方规则。

## Windows 启动

下载并解压发布包后双击 `start.cmd`，在浏览器打开 `http://127.0.0.1:8080/`。关闭控制台可停止服务。发布包已含 Windows 程序和前端产物，无需安装 Go、Node.js。

源码首次构建需要 Go 1.24+、Node.js 22.12+ 与 npm。本次使用 Go 1.27.3、Node.js 24.15。执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/run.ps1
```

启动脚本首次生成 `data/admin-key.txt`。在页面设置的管理入口填写该密钥可查看后台状态。玩家使用用户名和密码注册、登录；当前没有密码重置或找回功能。发布包不包含任何测试账号、会话、密钥或私有原包。

## Linux 与 Docker

发布包含 Linux amd64 程序，使用 `sh scripts/run.sh`；源码使用 `sh scripts/build.sh` 构建。跨平台编译已通过，Linux 实际运行和 Docker 构建尚未验收。

公网与手机访问的 HTTPS、域名、持久化和备份配置见 [部署说明](docs/DEPLOYMENT.md)。本地默认仅监听回环地址，手机不能直接访问电脑的 `127.0.0.1`。

## 可体验功能

大厅按原包的顶栏、左侧入桌/创房/茶馆、右侧游戏列表和底部入口重新组织。创建与加入房间、房间邀请链接、准备开局、合法操作提示、断线重连、逐局结算、战绩、规则、头像昵称、反馈、管理状态和监控接口均已接入。牌桌不提供电脑补位或自动托管；有多种响应可选时由玩家决定，只有过牌可选时自动过牌。牌类游戏由玩家自行选择组合出牌，服务端负责规则校验。

茶馆已提供创建/申请加入、入馆审核、公告、馆主/管理员/成员、禁玩/移除、固定玩法的新增修改和启停、馆内开桌入桌、自动补空桌、管理员解散、已完成局战绩与积分统计。茶馆任意成员可查看最近7天各房间的结算战绩；馆主/管理员可生成、轮换或撤销外部只读战绩 API 密钥，供其他团队开发的微信小程序等客户端调用。接口契约见 [茶馆战绩 API](docs/EXTERNAL_TEAHOUSE_RECORDS_API.md)；微信小程序本身由接入方开发，尚未做真实公网/微信验收。原版消息、馆内邀请、财富操作、大赢家设置、细分管理员权限及完整录像回放尚未实现。逐项对照见 [原版功能对照](docs/ORIGINAL_PARITY.md)。

手机布局、安装图标和添加主屏幕说明已提供；没有离线 Service Worker，也没有微信授权登录、短信、真实支付。战绩提供结算、记分账和最近事件，尚不提供整局逐步录像回放。
